# Additional chart forms and scales

Core rules are in SKILL.md; this reference is optional.

## Choose the form

- Categories: horizontal bars or dots. Before/after: paired dots/bars, or a table with deltas.
- Time: chronological lines, or bars for discrete periods. Leave gaps visible.
- Uncertain estimates: a point and interval, with the interval named. Distribution/association: histogram, boxplot or scatter only when underlying observations exist.
- Composition: stacked/100% bars only when components genuinely add up. Compare components using grouped bars or dots.
- Exact heterogeneous quantities: a table with separate labeled columns. Use separate panels for many series when that answers the question more clearly.

## Special cases

- Preserve natural time/stage order; otherwise order for the question. Separate totals from components; keep series order consistent between panels.
- Show negatives relative to a visible zero. Label logarithmic scales explicitly; do not apply them to zero/negative values.
- Profit may be assessed against zero; profitability has no universal 100% threshold. Show benchmarks only when known and labeled.
- For heatmaps, use sequential colors for magnitude and diverging colors for departures from a stated baseline. Add labels/hatching for similar shades; decorative legends do not repair too many colors.
- Disclose differences in totals, rounding, aggregation and methodology; never silently fix the source. An image does not replace a precise searchable/copyable table.
